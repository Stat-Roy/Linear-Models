1 Syllabus

1.1 Course Overview

This course develops the theory and application of linear models, beginning with the Gauss-Markov framework and ordinary least squares estimation, and progressing through regression analysis, analysis of variance, analysis of covariance, and model checking.

The course emphasizes both the mathematical foundations of linear estimation and the practical analysis of fitted models. Particular attention is given to estimation, hypothesis testing, model matrices, variance components, and diagnostic methods for assessing the adequacy of model assumptions.

The major topics covered in the course are:

  1. Gauss-Markov set-up
  2. Regression analysis
  3. Analysis of variance
  4. Model checking

1.2 1. Gauss-Markov Set-up

The Gauss-Markov framework provides the theoretical foundation for linear estimation. This section introduces linear estimators, estimability, least squares estimation, and the Gauss-Markov theorem.

1.2.1 Topics

  • Theory of linear estimation
  • Estimability of linear parametric functions
  • Method of least squares
  • Gauss-Markov theorem
  • Estimation of error variance

The general linear model may be written as

\[ \mathbf{Y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}, \]

where \(\mathbf{Y}\) is the vector of observations, \(\mathbf{X}\) is the model matrix, \(\boldsymbol{\beta}\) is the vector of unknown parameters, and \(\boldsymbol{\varepsilon}\) is the vector of random errors.

The least squares framework provides the basis for estimating \(\boldsymbol{\beta}\) and studying the properties of linear estimators.

1.3 2. Regression Analysis

Regression analysis studies the relationship between a response variable and one or more explanatory variables. The course covers both simple and multiple regression models, including estimation, hypothesis testing, and the role of the model matrix.

1.3.1 Topics

  • Simple regression analysis
  • Estimation in simple regression models
  • Hypothesis testing in simple regression models
  • Estimation in multiple regression models
  • Hypothesis testing in multiple regression models
  • Concept of the model matrix
  • Use of the model matrix in estimation

A simple linear regression model can be expressed as

\[ Y_i = \beta_0 + \beta_1 X_i + \varepsilon_i, \]

while a multiple regression model takes the form

$$ Y_i ===

_0 + 1 X{i1} + 2 X{i2} + + p X{ip} + _i. $$

In matrix notation, these models are represented by

\[ \mathbf{Y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}. \]

The model matrix \(\mathbf{X}\) plays a central role in estimation and provides a unified way of representing a wide range of linear models.

1.4 3. Analysis of Variance

Analysis of variance (ANOVA) extends the linear model framework to the analysis of data classified according to one or more factors. This section introduces fixed, random, and mixed effect models and develops methods for analysis of variance and covariance.

1.4.1 Topics

  • Definitions of fixed effect models
  • Definitions of random effect models
  • Definitions of mixed effect models
  • Analysis of variance and covariance in one-way classified data for fixed effect models
  • Analysis of variance and covariance in two-way classified data with one observation per cell
  • Analysis of variance and covariance in two-way classified data with an equal number of observations per cell
  • Two-way analysis for fixed, random, and mixed effect models
  • Analysis of covariance in a two-way layout

1.4.2 One-Way Classification

For one-way classified data, the observations can be represented using a model such as

\[ Y_{ij} = \mu + \alpha_i + \varepsilon_{ij}, \]

where \(\mu\) represents the overall mean, \(\alpha_i\) represents the effect associated with the \(i\)-th level of the factor, and \(\varepsilon_{ij}\) represents the random error.

The analysis separates the total variation into components attributable to the factor and to random error.

1.4.3 Two-Way Classification

Two-way classified data involve two factors and may be analyzed under different assumptions concerning the effects. Depending on the model, the effects may be treated as fixed, random, or mixed.

The analysis considers designs with:

  • One observation per cell
  • An equal number of observations per cell

The corresponding variance and covariance decompositions allow hypotheses concerning the effects to be tested within the linear model framework.

1.4.4 Analysis of Covariance

Analysis of covariance (ANCOVA) combines features of regression and analysis of variance. In a two-way layout, covariates can be incorporated into the model to account for additional sources of systematic variation.

1.5 4. Model Checking

A fitted linear model should not be accepted solely because its parameter estimates can be computed. The assumptions underlying the model must also be examined.

This section focuses on prediction from fitted models and diagnostic methods for detecting violations of common assumptions.

1.5.1 Topics

  • Prediction from a fitted model
  • Violation of the assumption of normality
  • Violation of the assumption of homoscedasticity
  • Violation of the assumption of collinearity
  • Diagnostics using quantile-quantile plots

Important assumptions and issues considered in model checking include:

1.5.2 Normality

The error terms are commonly assumed to follow a normal distribution:

\[ \varepsilon_i \sim N(0,\sigma^2). \]

Departures from normality can affect inference, particularly in small samples.

1.5.3 Homoscedasticity

The errors are assumed to have constant variance:

\[ \operatorname{Var}(\varepsilon_i) = \sigma^2. \]

When the variance changes with the level of the fitted values or explanatory variables, the assumption of homoscedasticity is violated.

1.5.4 Collinearity

In multiple regression, strong relationships among explanatory variables can lead to collinearity or multicollinearity. This can make individual parameter estimates unstable and complicate interpretation and hypothesis testing.

1.5.5 Quantile-Quantile Plots

Quantile-quantile (Q-Q) plots provide a graphical method for assessing whether observed residuals are consistent with a specified theoretical distribution, particularly the normal distribution.

A Q-Q plot is therefore an important diagnostic tool for examining the normality assumption of a fitted linear model.

1.6 Summary of the Syllabus

The course progresses from the theoretical foundations of linear estimation to increasingly general applications of the linear model:

\[ \boxed{ \text{Gauss-Markov Theory} ;\longrightarrow; \text{Regression} ;\longrightarrow; \text{ANOVA/ANCOVA} ;\longrightarrow; \text{Model Checking} } \]

The central theme throughout the course is the general linear model

\[ \mathbf{Y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}. \]

Understanding this framework provides a common foundation for least squares estimation, regression, analysis of variance, analysis of covariance, hypothesis testing, and model diagnostics.
